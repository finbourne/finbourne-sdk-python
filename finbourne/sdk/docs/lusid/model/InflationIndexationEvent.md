# InflationIndexationEvent

The day-on-day change in the indexed face of an inflation-linked bond, as its inflation index ratio moves  from one day to the next. A memo event: downstream it books a transaction whose units carry the day's indexed-face  change (the principal uplift) and whose cash is zero; nothing moves.  Mandatory participation.
## Properties

| Name | Type | Required | Description |
|------|------|----------|-------------|
| **currency** | **str** | Required | The bond&#39;s domestic currency. |
| **event_date** | **datetime** | Optional | The instant from which the new index ratio applies: the bond&#39;s local midnight on the indexation day. On an  event LUSID generates it is returned in UTC, and the event id names the bond&#39;s local calendar day. An  upserted event may give it with any offset; it is normalised to UTC when stored. |
| **index_ratio_after** | **float** | Required | The bond&#39;s un-floored inflation index ratio on the event date. |
| **index_ratio_before** | **float** | Required | The bond&#39;s un-floored inflation index ratio on the day before the event date. |
| **indexed_face_change_per_unit** | **float** | Required | The day&#39;s change in indexed face per unit: the un-indexed face per unit multiplied by  (index ratio after minus index ratio before). |
| **instrument_event_type** | **str** | Required | The Type of Event.
