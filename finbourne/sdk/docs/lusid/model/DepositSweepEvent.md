# DepositSweepEvent

Sweeps the portfolio's eligible cash for a currency into a STIF FlexibleDeposit. Carries no amount of  its own, because it is resolved at processing time.

|------|------|----------|-------------|
| **sweep_date** | **datetime** | Optional | Date the sweep is effective, and whose cash balance is swept. |
| **currency** | **str** | Required | Currency of the swept cash balance. |
