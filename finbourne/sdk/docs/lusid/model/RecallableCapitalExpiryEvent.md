# RecallableCapitalExpiryEvent

The lapse of a recallable portion of an earlier distribution on a CapitalInterest: the amount leaves  RecallableCapital and joins NonRecallableCapital. Raised when the recall window of the source  distribution closes.
## Properties

| Name | Type | Required | Description |
|------|------|----------|-------------|
| **var_date** | **datetime** | Optional | The date the recall window closes. |
| **amount** | **float** | Required | The recallable amount that lapses, in the commitment currency. Must be positive. |
| **source_distribution_event_id** | **str** | Required | The identifier of the distribution event whose recallable portion lapses. |
| **instrument_event_type** | **str** | Required | The Type of Event.
