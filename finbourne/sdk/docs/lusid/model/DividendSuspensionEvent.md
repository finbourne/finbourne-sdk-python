# DividendSuspensionEvent

An issuer's decision to skip one scheduled preferred dividend without defaulting. Suppresses the  intrinsic dividend for the targeted payment date only; the schedule and every other payment continue.
## Properties

| Name | Type | Required | Description |
|------|------|----------|-------------|
| **target_payment_date** | **datetime** | Optional | The intrinsically-scheduled dividend payment date this event suppresses. A date the instrument&#39;s  own schedule does not pay on leaves the event with no observable effect. |
| **announcement_date** | **datetime** | Optional | The date the issuer disclosed the suspension. Optional — null when not recorded. When populated,  must be &lt;&#x3D; TargetPaymentDate. |
| **instrument_event_type** | **str** | Required | The Type of Event.
