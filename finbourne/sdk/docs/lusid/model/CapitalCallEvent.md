# CapitalCallEvent

A call of committed capital on a CapitalInterest: the fund draws down the amount from the investor's  unfunded commitment, moving it to funded capital.
## Properties

| Name | Type | Required | Description |
|------|------|----------|-------------|
| **var_date** | **datetime** | Optional | The date the capital call takes effect. |
| **amount** | **float** | Required | The amount of committed capital called. Must be positive. |
