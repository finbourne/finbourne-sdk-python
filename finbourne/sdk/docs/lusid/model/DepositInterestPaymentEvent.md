# DepositInterestPaymentEvent

Event to signify the repayment of interest accrued against a deposit holding. Not applied when upserted  for a period the deposit settles partly or wholly in kind, as its scheduled events settle that period's interest.
## Properties

| Name | Type | Required | Description |
|------|------|----------|-------------|
| **payment_date** | **datetime** | Optional | Date that the interest is due to be paid. |
| **ex_date** | **datetime** | Optional | Date that the accrued interest is calculated up until. |
| **currency** | **str** | Required | Currency of the repayment. |
| **fraction** | **float** | Optional | Fraction of the accrued interest to be paid, between 0 and 1 inclusive. Defaults to 1 if not set. |
| **lapse_elections** | [List[LapseElection]](LapseElection.md) | Optional | Election for controlling whether the interest is paid. Stored but not yet acted on, so a chosen  lapse election does not stop the payment. Optional; if provided, exactly one. |
