# PaymentInKindEvent

A Payment in Kind (PINK) event recording that a ComplexBond has paid a coupon in kind. Mandatory and  purely informational: it carries no entitlement and generates no cash flow, movements or transactions,  and leaves Units, current face, PV and accrual untouched. The accretion itself stays with the intrinsic  chain driven by the bond's PikSchedule.
## Properties

| Name | Type | Required | Description |
|------|------|----------|-------------|
| **ex_date** | **datetime** | Optional | The first business day on which the in-kind coupon is not owed to the buying party. Anchors the  lifecycle; must be on or before PaymentDate. |
| **payment_date** | **datetime** | Optional | The payment date of the in-kind coupon this marker records. |
| **announcement_date** | **datetime** | Optional | Date on which the issuer announced the payment in kind. Optional and informational. |
| **record_date** | **datetime** | Optional | Date on which the holder of record is struck. Optional and informational; when supplied it must fall  on or between ExDate and PaymentDate. |
| **currency** | **str** | Optional | Currency of the coupon that was paid in kind. Optional and informational. |
