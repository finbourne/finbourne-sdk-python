# DepositInterestCapitalisationEvent

Event to signify that interest accrued against a deposit holding is capitalised into the deposit's  balance instead of being paid in cash.
## Properties

| Name | Type | Required | Description |
|------|------|----------|-------------|
| **payment_date** | **datetime** | Optional | Date that the capitalisation is effective. Capitalisation has no cash to settle, so nothing can lag  the accrual it capitalises and this is the ex-date. |
| **ex_date** | **datetime** | Optional | Date that the in-kind accrued interest is calculated up until. |
| **currency** | **str** | Required | Currency of the capitalised amount. |
| **fraction** | **float** | Optional | Fraction of the in-kind accrued on the holding to be capitalised. Must be between 0 and 1, inclusive.  Defaults to 1 if not set. |
| **lapse_elections** | [List[LapseElection]](LapseElection.md) | Optional | Election for controlling whether the interest is capitalised automatically or not.  Exactly one election must be provided. |
| **instrument_event_type** | **str** | Required | The Type of Event.
