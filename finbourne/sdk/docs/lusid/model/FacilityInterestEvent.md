# FacilityInterestEvent

Interest accrued on the drawn balance of a fund-level credit facility for a period, at the facility rate  on the given day-count basis: outstanding x rate x days / basis. A partnership expense that is allocated  to partners like other fund expenses; it never moves a partner's capital balances.
## Properties

| Name | Type | Required | Description |
|------|------|----------|-------------|
| **facility_id** | **str** | Required | The code of the facility on the fund that the event relates to. |
| **period_start** | **datetime** | Optional | The first day of the accrual period. |
| **var_date** | **datetime** | Optional | The last day of the accrual period; the date the interest is booked. |
| **outstanding** | **float** | Required | The drawn balance the interest accrues on, in the facility currency. Must be positive. |
| **rate** | **float** | Required | The annual interest rate of the facility (reference rate plus margin) as a decimal fraction, e.g. 0.06 for 6%. |
| **day_count_convention** | **str** | Required | The day-count convention the accrual is calculated on, e.g. Act360, Act365 or Thirty360. |
| **currency** | **str** | Required | The currency of the facility, in which the amount is denominated. |
| **instrument_event_type** | **str** | Required | The Type of Event.
