# OverrideVirtualTransactionsRequest

Upserts overrides, suppressions and adjustments of virtual transactions generated by a single instrument event.  Overrides and adjustments are keyed by the virtual transaction id they target; suppressions are the list of  virtual transaction ids being suppressed. A virtual transaction id must appear in only one of them. This is a  full replace of the previously stored overrides, suppressions and adjustments for the targeted instrument  event - any previously stored entry not present in this request is removed.
## Properties

| Name | Type | Required | Description |
|------|------|----------|-------------|
| **overrides** | **Dict[str, Optional[List[OverrideDefinitionRequest]]]** | Optional | A map of virtual transaction id to one or more replacement transactions. A virtual transaction id cannot also appear in Suppressions. |
| **suppressions** | **List[str]** | Optional | The virtual transaction ids to suppress. A virtual transaction id cannot also appear in Overrides. |
| **adjustments** | [Dict[str, AdjustmentDefinitionRequest]](AdjustmentDefinitionRequest.md) | Optional | A map of virtual transaction id to the fields to change on it. Fields left out keep following the instrument event. A virtual transaction id cannot also appear in Overrides or Suppressions. |
