# AdjustmentDefinitionRequest

The fields to change on a virtual transaction generated by an instrument event; every field left out keeps  following the event.
## Properties

| Name | Type | Required | Description |
|------|------|----------|-------------|
| **settlement_date** | **str** | Optional | The settlement date to use in place of the instrument event&#39;s. |
| **units** | **float** | Optional | The units to use in place of the instrument event&#39;s. The total consideration is worked out again unless it is also supplied. |
| **trade_price** | **float** | Optional | The price to use in place of the instrument event&#39;s. The total consideration is worked out again unless it is also supplied. |
| **total_consideration** | **float** | Optional | The total consideration, in the settlement currency, to use in place of the instrument event&#39;s. It is also used as the gross consideration. Must be greater than zero. |
| **exchange_rate** | **float** | Optional | The exchange rate from the trade currency to the settlement currency. The total consideration is worked out again at this rate unless it is also supplied. Must be greater than zero, and is required when the settlement currency is changed. |
| **settlement_currency** | **str** | Optional | The settlement currency to use in place of the instrument event&#39;s. Requires an exchange rate. |
| **custodian_account_id** | [ResourceId](ResourceId.md) | Optional | *No description available.* |
| **properties** | [Dict[str, PerpetualProperty]](PerpetualProperty.md) | Optional | Properties to set on the virtual transaction, replacing any it carries with the same key. |
| **transaction_id** | **str** | Optional | The transaction id to book the virtual transaction under in place of the generated one. Must not be used by any other transaction in the portfolio. The override stays keyed on the generated id. Settlement instructions, and instrument event instructions that name a tax lot this transaction opens, must then use the new id. |
