# PariPassuEvent

Pari-Passu event (PARI) — a mandatory reorganisation in which two securities with  different characteristics become fungible and are merged into a single class on the  assimilation payment date. Holders of record on the record date have their positions  converted automatically to the new ISIN at a fixed 1:1 ratio with cost basis preserved.
## Properties

| Name | Type | Required | Description |
|------|------|----------|-------------|
| **record_date** | **datetime** | Optional | The record date — the eligibility cutoff. Holders of record on this date enter the  assimilation. Required per AMI-SeCo Annex 2 (Record Date Required &#x3D; Yes for PARI). |
| **payment_date** | **datetime** | Optional | The payment date — the date the assimilation fires and the paired StockMovement  transactions land. Required per AMI-SeCo § 4.42 Table 108 Key Date. |
