# PikBondPrincipalEvent

Definition of a PIK Bond Principal Event  This is an event that describes the principal repayment of a Payment-in-Kind ComplexBond at  maturity or redemption.
## Properties

| Name | Type | Required | Description |
|------|------|----------|-------------|
| **ex_date** | **datetime** | Optional | The ex date (entitlement date) of the principal payment |
| **payment_date** | **datetime** | Optional | The payment date of the principal |
| **currency** | **str** | Required | The currency in which the principal is expressed |
| **principal_per_unit** | **float** | Optional | The principal amount per unit of the held bond&#39;s current face |
