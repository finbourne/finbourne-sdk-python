# FacilityDrawEvent

A drawdown on a fund-level credit facility recorded against a CapitalInterest: cash comes in and the  facility payable goes up by the same amount. Financing, not capital: no partner balance moves.
## Properties

| Name | Type | Required | Description |
|------|------|----------|-------------|
| **facility_id** | **str** | Required | The code of the facility on the fund that the event relates to. |
| **var_date** | **datetime** | Optional | The date the draw is made. |
| **amount** | **float** | Required | The principal drawn, in the facility currency. Must be positive. |
| **currency** | **str** | Required | The currency of the facility, in which the amount is denominated. |
| **purpose** | **str** | Optional | What the draw funds: a deal identifier or an expense description. Optional. |
| **instrument_event_type** | **str** | Required | The Type of Event.
