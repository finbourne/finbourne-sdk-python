# AmendCommitmentEvent

Amends the total committed capital of a CapitalInterest. A positive amount increases the commitment and a  negative amount decreases it.
## Properties

| Name | Type | Required | Description |
|------|------|----------|-------------|
| **var_date** | **datetime** | Optional | The date the commitment amendment takes effect. |
| **amount** | **float** | Required | The signed change to the total commitment. Positive implies an increase, and negative implies a  decrease. |
| **component** | **str** | Optional | The component of the commitment the amendment is recorded under: &#39;Commitment&#39; for a commitment made  or upsized, &#39;Release&#39; for committed capital released. Optional; when absent the sign of the amount  decides. |
| **instrument_event_type** | **str** | Required | The Type of Event.
